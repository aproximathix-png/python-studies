# Contact Book

A simple contact management application built with Python. This project allows users to store, view, search, update, and delete contacts through a command-line interface.

## Features

- **Add contacts:** Store a contact's name, email address, and phone number.
- **View contacts:** Display all saved contacts.
- **Delete contacts:** Remove a contact using its index.
- **Update contacts:** Modify a contact's name, email address, or phone number.
- **Search contacts:** Find a contact by name.
- **Data persistence:** Save contacts to a JSON file and load them when the program starts.
- **Input validation:** Handle invalid menu choices and contact information.

## Technologies Used

- Python
- JSON
- `json` module
- Lists and dictionaries
- Loops and conditional statements

## How to Run

1. Make sure Python is installed.
2. Clone this repository or download the project.
3. Navigate to the project folder.
4. Run the following command:

```bash
python main.py
```

## Data Storage

Contacts are stored in a JSON file. When the program starts, it loads previously saved contacts. Changes are saved so that contacts remain available between sessions.
