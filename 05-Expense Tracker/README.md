Features
Add Expenses: Enter an expense name, quantity, and price.
View Expenses: Display all recorded expenses.
Delete Expenses: Remove an expense using its index.
Calculate Total Spending: Calculate the total cost of all expenses.
Input Validation: Prevent empty names, invalid numbers, negative values, and invalid menu choices.
JSON Persistence: Save expenses to a JSON file and load them automatically when the program starts.


Data Storage
Expenses are stored in data.json.
The program automatically loads previously saved expenses when it starts and saves changes so that data is preserved between sessions.
If the JSON file does not exist, the program starts with an empty expense list.
